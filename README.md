# Flutter-from-cs

# ชื่อแอป DDR
Application: DDR 
โปรเจกต์แอปพลิเคชันบนมือถือสำหรับบันทึกกิจกรรมและความรู้สึกในแต่ละวัน
เป็นส่วนหนึ่งของรายวิชาการพัฒนาโปรแกรมประยุกต์บนอุปกรณ์พกพา โดยมีจุดประสงค์เพื่อฝึกพัฒนาแอปพลิเคชันและเรียนรู้การจัดเก็บข้อมูลในรูปแบบต่าง ๆ

## เทคโนโลยีที่ใช้
*   **Language:** `Dart`
*   **Framework:** `Flutter`
*   **Local Database:** `SQLite`
*   **Backend Communication:** `REST API`
*   **Cloud Services:** `Firebase`
*   **Authentication:** `Firebase Authentication` (Email/Password)

## ฟีเจอร์
- สมัครสมาชิก/เข้าสู่ระบบด้วย Email/Password
- CRUD สร้าง/แสดงข้อมูล/แก้/ลบบันทึก โดยแบ่งเป็น3แบบหลักๆ ดังนี้:
    - Local DB storage หรือ SQLite (เก็บในเครื่องผู้ใช้)
    - REST API (เก็บใน server)
    - Cloud (เก็บบนระบบอินเทอร์เน็ต)
- สามารถกดเจนเนอร์เรท คำคมได้
- สามารถบันทึกคำคมที่ชอบได้

## หน้าการทำงาน
| หน้าแรก  | สมัครสมาชิก/เข้าสู่ระบบ |
| :--- | :--- |
| หน้าหลัก | รายละเอียดการทำงาน |
| :--- | :--- |
| **บันทึก** | จัดการไดอารีและข้อมูลที่บันทึกไว้ในเครื่อง (Local) |
| **ออนไลน์** | จัดการข้อมูลผ่าน REST API ที่เชื่อมต่อกับเซิร์ฟเวอร์ |
| **Cloud** | จัดการข้อมูลผ่านบริการคลาวด์ |
| **เกี่ยวกับ** | แสดงข้อมูลเกี่ยวกับแอปพลิเคชันและผู้พัฒนา |

## วิธีติดตั้ง
1. ดาวน์โหลด app-release.apk
2. เปิดไฟล์บนมือถือ Android
3. อนุญาตติดตั้งจากแหล่งไม่รู้จัก
4. เปิดแอป สมัครบัญชี เริ่มใช้
